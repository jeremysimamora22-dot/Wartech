# WarTech - Aplikasi Penjualan Sederhana Warung/Kantin

HTML + CSS + JavaScript + Bootstrap 5 (tanpa Tailwind, tanpa React, tanpa npm).

## Menjalankan
Klik dua kali `login.html` atau `index.html` (butuh internet untuk memuat Bootstrap, ikon, Chart.js, dan font dari CDN).
Alternatif: VS Code + Live Server, atau Laragon: `http://localhost/wartech-login/`.

## Akun demo
Admin: `admin` / `admin123`  (atau email `admin@wartech.com`)

## Data
Semua data disimpan di localStorage browser. Untuk mengembalikan data awal, buka Console (F12) lalu jalankan `localStorage.clear()` dan muat ulang.
